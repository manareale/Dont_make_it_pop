## Commandes du personnage :
- Pour les déplacements physiques : 
    WASD et les flèches
- Pour le déplacement de la caméra : 
    Mouvement de la souris
- Pour activer le boost de vitesse :
    Touche SHIFT
- Pour esquiver les obstacles :
    Barre d'espacement

## Description de l'interaction présente dans le prototype :
Le personnage principal est une fermière qui tente de s'échapper d'un labyrinthe d'épis de maïs. La fermière doit récupérer les épis nécessaires pour s'enfuir tandis qu'elle se fait courir après par un épouvantail.
